# Sello

**Live demo:** https://dhunidesigns.github.io/Sello/

An AI sales assistant for Instagram sellers. Sello answers routine DMs from the seller's real prices and stock, and hands over to the seller for payments, discounts, complaints and anything it isn't sure about.

Built with Next.js (App Router) and TypeScript. Mobile-first.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Screens built

- `/` — 01 Onboarding / Welcome: the orange rises from the bottom and settles into the top glow, the content pops in, and the Get started button finishes with a shine. Double-tap the app icon to replay. Get started slides Create account up as a layer while the orange fades underneath.
- `/create-account` — 02 Onboarding, as a chat with Sello: Sello asks for your email, your typing lights up letter by letter like Apple Music lyrics, and the email flies up into your bubble. Sello replies asking for the code. A wrong code shakes the button and Sello says so; the right one (`567 758` in this demo) grows the button into the "You're in!" sheet with a floating 3D Sello icon.
